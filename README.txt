NAKUL LINK HUB

Included files:
- index.html: responsive link-in-bio page
- profile.jpg: your cropped profile photo
- background.mp4: original seamless animated starfield background video

The background video was created for this page (not copied from a third-party clip), so there is no stock-video attribution requirement.

GitHub Pages setup:
1. Create a repository, e.g. nakul-links.
2. Upload ALL THREE files to the repository root (index.html, profile.jpg, background.mp4).
3. Open Settings -> Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Open the published Pages URL.

Keep the three files together in the same folder. The video is muted and loops automatically; phones may require the page to be opened normally for autoplay.
